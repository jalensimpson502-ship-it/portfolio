# Jalen Portfolio Site

## How to edit
- Main page: `index.html`
- Styling: `assets/styles.css`
- Small scroll animations: `assets/script.js`
- Project case studies: `projects/*.html`

## Replace placeholders
1. Update email / LinkedIn / resume links in `index.html`.
2. Replace the CSS mock visuals with actual `<img>` or `<video>` elements.
3. Put image/video files in `assets/`.
4. Replace project page placeholder blocks with real media or embeds.
5. Replace any confidential project wording before publishing.

## Example image
```html
<img src="../assets/my-project-photo.jpg" alt="Short description">
```

## Example video
```html
<video autoplay muted loop playsinline controls>
  <source src="../assets/demo.mp4" type="video/mp4">
</video>
```

## Example YouTube embed
```html
<iframe src="https://www.youtube.com/embed/VIDEO_ID"
        title="Project demo"
        allowfullscreen></iframe>
```

## Publishing free
You can publish this folder on GitHub Pages or Cloudflare Pages.
