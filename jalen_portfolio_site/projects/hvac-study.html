The Problem

What needed to be solved?

The first comparison completed before my co-op rotation looked reasonable but did not fully account for outside-air percentage. That meant nominal tonnage alone could create a misleading comparison between equipment configurations.

02

My Approach

How I attacked it.

I revised the model rather than defending the first version. The comparison was rebuilt around how the units would actually operate: outside-air requirements, run time, heat-pump share, gas efficiency, emissions factors, and configuration differences.

03

Impact

Why the work mattered.

The study became a more credible decision framework because it compared real application conditions instead of only nominal equipment sizes, giving stakeholders a clearer way to discuss future standards and tradeoffs.

Takeaway

The biggest takeaway from this project was that a study can always be more detailed. The goal is to limit assumptions in order to continously improve the decision-making process. The results of this project demonstrated the value of iterative analysis and futher stakeholder engagement.
